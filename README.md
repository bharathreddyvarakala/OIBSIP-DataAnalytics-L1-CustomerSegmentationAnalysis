Customer Segmentation Analysis

Overview

This project performs customer segmentation on an e-commerce dataset using the K-Means clustering algorithm. It analyses customer purchasing behaviour to identify distinct customer groups and recommend suitable marketing strategies.

Dataset

The project uses the **Online Retail dataset** from Kaggle, loaded directly using KaggleHub. The dataset contains transaction details such as customer IDs, invoice dates, quantities, and unit prices.

Technologies Used

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* Scikit-learn
* KaggleHub
* Jupyter Notebook

Key Features

* Dataset inspection and data cleaning
* Descriptive statistical analysis
* RFM analysis using Recency, Frequency, and Monetary value
* Data standardisation using StandardScaler
* Optimal cluster selection using the Elbow Method
* Customer segmentation using K-Means
* Cluster visualisation and customer profiling
* Marketing recommendations for each customer segment

Output

The project generates visualisations of customer clusters, a summary of customer behaviour for each segment, and marketing recommendations based on the clustering results. The segmentation results are also saved as a CSV file.

Objective

To identify meaningful customer groups based on purchasing behaviour and support data-driven marketing and customer-retention decisions.
